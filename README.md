# myanmar-date

[![crates.io](https://img.shields.io/crates/v/myanmar-date.svg)](https://crates.io/crates/myanmar-date)
[![docs.rs](https://img.shields.io/docsrs/myanmar-date)](https://docs.rs/myanmar-date)
[![license](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](#license)

A small, dependency-light Rust library for converting between **Gregorian**
and **Myanmar (Burmese) lunisolar** calendar dates.

The calculation logic is ported from
[yan9a/mmcal](https://github.com/yan9a/mmcal) (MIT, © 2018 Yan Naing Aye) —
see [`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md) for full attribution
and license text.

## Status: Phase 1

This release covers **Gregorian <-> Myanmar date conversion** and the
calendar value types. Astrological days (Sabbath, Yatyaza, Mahabote, Nakhat,
year name, ...) and the Thingyan calculation are planned for a later release.
This crate deliberately never labels a day a "holiday" — that's policy, not
calendrical fact, and is left to the consumer.

## Features

- **`no_std` core with zero required dependencies.** Every conversion is
  pure, allocation-free arithmetic over `Copy` value types.
- **`chrono` integration** (default-on): convert directly to/from
  `chrono::NaiveDate`.
- **English names always available**; **Burmese-script names** behind the
  optional `burmese` feature (purely additive — enabling it never changes
  existing behavior).
- **Never returns a wrong date.** Out-of-range or invalid input returns
  `Err`, not silently-wrong output. Supported range: Gregorian years 640–9999
  CE, checked against the upstream reference implementation across every
  historical era boundary and documented exception year (see
  `tests/fixtures/golden_vectors.csv`, generated by
  `util/generate_fixtures.js`).

## Usage

```rust
use myanmar_date::{GregorianDate, MyanmarDate};

fn main() -> Result<(), myanmar_date::Error> {
    let gregorian = GregorianDate::new(2024, 1, 1)?;
    let myanmar = MyanmarDate::from_gregorian(gregorian)?;

    assert_eq!(myanmar.year(), 1385);
    assert_eq!(myanmar.sasana_year(), 2567);
    assert_eq!(myanmar.to_gregorian(), gregorian);
    Ok(())
}
```

With the default `chrono` feature:

```rust
use chrono::NaiveDate;
use myanmar_date::MyanmarDate;

let today = NaiveDate::from_ymd_opt(2024, 1, 1).unwrap();
let myanmar = MyanmarDate::try_from(today)?;
assert_eq!(myanmar.year(), 1385);
# Ok::<(), myanmar_date::Error>(())
```

See `examples/basic.rs` for a runnable version of the example above
(`cargo run --example basic`).
